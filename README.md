# SiteTrack Pro

Progressive Web App for construction-site attendance, work completion, safety, materials, and reporting.

## Included

- Responsive dashboard for desktop, tablet, and mobile
- Project progress, attendance, safety, work, and reports views
- Quick attendance check-in interaction with GPS/device status presentation
- Search and project filtering
- Dark mode and mobile bottom navigation
- PWA manifest and offline service-worker shell
- Realistic construction demo data
- Vinext/Cloudflare-compatible production build

## Run locally

```bash
npm install
npm run dev
```

Build for production with:

```bash
npm run build
```

## Product scope

This repository contains the polished interactive front-end release. The next backend phase can connect authentication, PostgreSQL persistence, real GPS/photo capture, approval workflows, notifications, and report exports.
